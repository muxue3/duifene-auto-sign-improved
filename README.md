# 对分易自动签到 - 改进版

> 基于 [liuzhijie443/duifene_auto_sign](https://github.com/liuzhijie443/duifene_auto_sign) 修改增强

原项目作者：liuzhijie443，本仓库仅作为个人学习使用，感谢原作者的开源贡献。

## 相比原版的改进

### Bug 修复
- 修复二维码签到返回值判断错误（原代码无论成功失败都返回 True）
- 修复 Cookie 解析 bug，`split('=')` 改为 `split('=', 1)` 防止 value 含 = 号导致解析异常
- 修复 `get_user_id()` 空指针异常（增加 None 判断）
- 修复定位签到缺少返回值的问题
- 增加签到码 `isdigit()` 类型校验

### 新增功能
- 定时任务管理：支持添加/删除/保存定时签到任务，自动按时间切换课程
- 自动监听模式：根据时间表自动切换课程并监听签到，支持签到成功/未签到记录
- 签到历史面板：永久保存签到成功和未签到记录
- 网络请求重试机制：`request_with_retry()` 带重试的网络请求封装
- 登录状态自动检测：自动检测 Cookie 过期，网络连续异常才提示

### 代码优化
- Course 类从类变量重构为实例变量，增加多个状态管理属性
- 登录检查从每秒一次优化为每 60 秒一次
- 签到延迟等待机制：支持配置等待秒数
- 异常处理增强：所有网络请求增加异常捕获和日志输出
- UI 界面重新布局，增加定时任务列表和签到历史面板

## 使用方法

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行程序：
```bash
python main.py
```

3. 登录方式：通过微信链接登录（与原版相同）
